# Work Management Tools

## General Use

Use official accounts and company-approved tools for work-related communication and information. Do not use personal email accounts or unofficial platforms for sensitive or company-related correspondence.

## Google Workspace

Each employee receives a Google Workspace account on the **first day of employment**, including an official email address in the form `firstname@staunch.co`.

### Calendar

Use [Google Calendar](https://calendar.google.com/) to:

- check team availability;
- schedule meetings without conflicts;
- create events and reminders;
- track deadlines; and
- share calendars with colleagues.

### Meet and Chat

Use Google Meet for video conferences and Google Chat for instant messaging when those channels are appropriate.

### Email signature

Set up the official email signature with:

- full name;
- department and designation; and
- the Staunch company logo.

## Slack

Slack is the primary real-time communication and collaboration tool for internal teams and clients.

- Use channels organized by project, team, or topic for discoverable, focused discussion.
- Use direct messages for one-to-one or small-group conversations.
- Install the desktop application so that you receive real-time announcements and project or client updates.

The [focus-hours policy](focus-hours-policy.md) defines focus-status and Do Not Disturb requirements. The [leave policy](benefits/leave-policy.md) defines when to post leave notifications.

## Hubstaff

Hubstaff is used for time tracking, attendance, productivity monitoring, project-hour reporting, team-performance reporting, and billing support. It also takes screenshots at intervals through a built-in feature that employees cannot control.

The [working-hours and attendance policy](benefits/working-hours-and-attendance.md) defines eligible activity, manual-time notes and limits, attendance thresholds, and overtime.

> **Needs HR confirmation:** The source does not define the screenshot interval, who may view screenshots, how long they are retained, or how an employee can challenge an inaccurate or inappropriate record.

## ClickUp

ClickUp is the company system for project and task management.

- Assign tasks with clear descriptions, deadlines, priorities, and owners.
- Use List, Board, Calendar, or Gantt views to track work and timelines.
- Set measurable goals and monitor progress.
- Put task updates, comments, and attachments on the relevant task.
- Use ClickUp for company documents, project timelines, appraisal boards, and individually shared KPIs.

## Workable

Workable supports:

- recruitment and candidate sourcing;
- onboarding and electronic signatures;
- time-off requests and approvals; and
- employee records.

The [leave policy](benefits/leave-policy.md) defines the required Workable request and approval process.

## GitHub

GitHub is the code version-control and engineering collaboration platform.

- Store code in repositories and preserve version history.
- Collaborate through pull requests, code reviews, and issue tracking.
- Use GitHub Actions for approved automated workflows such as continuous integration and deployment.
